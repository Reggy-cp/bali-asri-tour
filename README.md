# Bali Asri Tour Website

Official modern Next.js 15 web platform for **Bali Asri Tour** — trusted, certified local tour operators and private drivers in Bali.

- **Live URL:** [https://bali-asri-tour.vercel.app](https://bali-asri-tour.vercel.app)
- **Repository:** [https://github.com/Reggy-cp/bali-asri-tour](https://github.com/Reggy-cp/bali-asri-tour)

---

## Features

- **Next.js 15 App Router:** High performance, SEO optimized, and fully statically generated (53 routes).
- **Modern Responsive Design:** Tailored for mobile, tablet, and desktop with Tailwind CSS.
- **Tour Booking Engine:** Direct WhatsApp integration for custom itineraries, car rentals, and transfers.
- **TripAdvisor Integration:** Real Travelers' Choice badge, 5-star review showcases, and customer testimonials.
- **Complete Page Suite:**
  - Homepage with curated tour categories and popular adventures
  - Category pages (Bali Day Tours, Bali Experience, Honeymoon, Packages, Airport Transfer, Book a Car)
  - 17+ Full Tour Detail pages with Day-by-Day Itineraries, Pricing Tables, and Inclusions
  - Dynamic Blog engine with SEO articles and travel guides
  - Company pages: About, Our Team, Charity, Reviews & Gallery, Contact, Terms & Conditions, Privacy Policy

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the site in your browser.

### 3. Run Automated Tests
```bash
npm test
```

### 4. Build for Production
```bash
npm run build
npm start
```

---

## Deployment on Vercel

The project is preconfigured for zero-config deployment on Vercel:
```bash
vercel --prod
```
Or connect your GitHub repository `Reggy-cp/bali-asri-tour` on [vercel.com](https://vercel.com) for automatic CI/CD deployments on git push.
